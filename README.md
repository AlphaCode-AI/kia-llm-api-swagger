# Kia LLM API Swagger

This repository preserves a historical API specification and its documentation assets. It remains available for reference.

For an active deployment, confirm the API contract against that deployment's generated documentation and matching server source. The files in this repository should not be assumed to describe the current production API.

This documentation update does not change or remove the existing specification, branches, or assets. Deployment addresses, access credentials, and internal operating instructions are intentionally kept out of this public repository.
